Demopost

A simple backend project built using Node.js, Express.js, and MongoDB.

## Features
- Create posts with images and captions.
- Upload images using ImageKit.
- Store posts in MongoDB.
- Fetch all posts using an API.

## Technologies
- Node.js
- Express.js
- MongoDB
- Mongoose
- Multer
- ImageKit

## Installation
1. Clone the repository.
2. Run `npm install`.
3. Add your environment variables in a `.env` file.
4. Run `node server.js`.

## API Routes
- `POST /create-post` — Create a post with an image and caption.
- `GET /posts` — Fetch all posts.
